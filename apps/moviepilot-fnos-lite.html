这是什么

把开源的 MoviePilot 裁剪打包成飞牛 fnOS 应用中心可直接安装的 FPK。不用 SSH 敲命令、不用装 Docker、不用研究环境变量 —— 装上就能用，影视库自动整理进你的媒体目录。

同时针对国内环境做了精简与增强：去掉国内用不上的模块、修复了飞牛下的路径与权限问题、并加入豆瓣中文名兜底等实用特性。

核心特性

  • 原生 FPK 安装 —— 应用中心一键安装/升级，数据保留在独立目录，卸载重装不丢配置
  • 自动整理 —— 监控下载目录，自动识别、刮削、硬链接入库，原文件不动，不产生重复占用
  • 默认硬链接 —— 同盘整理零拷贝，做种与入库两不误
  • 中文译名命名 —— TMDB 只有英文名时自动用豆瓣中文名兜底，如「圣诞好戏 Merry Christmas Aubrey Flint (2026)」，飞牛播放器刮削友好
  • 开箱即用 —— 内置站点辅助与常见配置模板，首次启动有引导

安装步骤

  1. 下载安装包

    点击上方下载按钮，得到 moviepilot-fnos-lite-1.0.8.fpk。

  2. 打开飞牛应用中心

    fnOS 桌面 →「应用中心」→ 左下角选择「手动安装」，在弹出的安装选择页面中选择安装位置以及文件来源（实际文件存放位置），选中下载的 fpk 文件，然后按照提示安装即可。

  3. 设置服务端口

    安装向导会让你填服务端口，默认 3011 直接下一步；如果 3011 已被别的程序占用（比如旧版 Docker MoviePilot），改成 3012 之类空闲端口再继续。

  4. 等待安装完成

    首次安装约 1~2 分钟。完成后桌面出现「MP 入库助手」图标，点击进入即可开始配置。

更详细的图文步骤与常见报错排查，见教程 《飞牛 fnOS 安装第三方 FPK 应用》。

常见问题

  • 升级会丢配置吗？ 不会。配置保存在 fnOS 应用数据目录，覆盖安装自动继承。
  • 和 Docker 版 MoviePilot 有什么区别？ 功能上是精简子集，胜在零配置门槛、与 fnOS 深度集成（权限、目录、开机自启）。
  • 为什么文件名变成了「中文名 + 英文名」？ 这是 v1.0.4 新特性，兼顾国内播放器刮削与源站识别，可在设置中关闭。
  • 3011 端口被占用怎么办？ v1.0.6 起安装向导里就能改端口；装好之后进「应用中心 → MP 入库助手 → 设置」也能改，保存后应用自动重启、桌面图标自动指向新端口。
